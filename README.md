## Hi there 👋

I build **quantitative trading systems**, **cryptographic tools**, and **Web3 applications**.

🔭 **Projects**
- **Authenticator 2FA** — Client-side TOTP with Argon2id + AES-256-GCM. MetaMask, Bitcoin, WebAuthn, Google & Password backup. Rust → WASM → Python crypto stack.  
  `https://2faotp.vercel.app`
- **GILD-AI Terminal** — Algorithmic trading terminal using Smart Money Concepts (SMC/ICT), liquidity sweeps, and order block detection.

🌱 **Deep areas**: Rust & AssemblyScript → WASM, Argon2id KDF, AES-256-GCM, WebAuthn FIDO2, PWA offline architecture, MQL5/PineScript strategy automation.
